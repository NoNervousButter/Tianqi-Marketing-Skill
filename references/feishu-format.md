# 飞书交付格式

遵循本对话最终案例格式，按素材和用户范围选择相应章节：一、案例概览（概述＋维度/内容表）；二、独立站活动页拆解（页面/拆解双列表，逐行对应截图与分析）；三、EDM邮件拆解（发送背景、Subject/Preheader、邮件内容/拆解表、整体分析和最多3条可关注内容）。无素材的章节标明未获取，勿虚构。用户要求只补充某节时只改对应章节，保持原有内容。

写入前读取目标文档并核对章节和表格；使用当前可用飞书工具，若使用lark-cli，先读取与操作匹配的内置指南。截图裁切按真实模块边界而非固定高度，保留标题、CTA及必要上下文；先目视检查裁切，再插入对应单元格。记录每张图与目标行的映射；遇到权限、插入或上传失败时保留已有内容并报告实际状态。写完回读验证章节、文字、截图数量、位置与对应关系；如无法目视验证布局，如实说明。

活动来源链接和截图依据应保留；过期活动页若重定向，注明历史搜索结果而非声称当前页面仍可访问。截图涉及私人邮箱、优惠码等信息时，根据任务需求避免无关暴露。
